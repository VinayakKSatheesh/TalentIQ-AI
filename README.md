# TalentIQ AI

AI-powered Talent Intelligence Platform built for the Data & AI Challenge.

## Features

- Semantic Candidate Search
- Vector Embeddings
- LLM Candidate Ranking
- Explainable AI
- Recruiter Dashboard
- Submission Generator

## Tech Stack

- FastAPI
- React
- Sentence Transformers
- FAISS
- OpenAI
- Tailwind CSS
